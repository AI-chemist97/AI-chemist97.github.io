## Git을 활용한 프로젝트 보조 도구 개발

### 1. 프로젝트 생성

#### 1.1 새로운 Git 저장소
- **명령어**: `git init`
- **설명**: 현재 디렉토리에서 새로운 Git 저장소 초기화.

#### 1.2 README 파일 생성
- **명령어**: 
  ```bash
  touch README.md
  ```
- **내용**: 프로젝트 목표, 설치 방법, 사용법 기록.

### 2. 파일 추가 및 커밋

#### 2.1 파일 추가
- **명령어**: `git add [file]`
- **설명**: 변경된 파일을 스테이징 영역에 추가.

#### 2.2 커밋
- **명령어**: `git commit -m "[message]"`
- **설명**: 스테이징된 변경 사항을 로컬 저장소에 저장.

### 3. 브랜치 관리

#### 3.1 브랜치 생성
- **명령어**: `git branch [branch-name]`
- **설명**: 새로운 브랜치 생성.

#### 3.2 브랜치 전환
- **명령어**: `git checkout [branch-name]`
- **설명**: 다른 브랜치로 전환.

### 4. 원격 저장소와의 연동

#### 4.1 원격 저장소 연결
- **명령어**: `git remote add origin [repository-url]`
- **설명**: 원격 저장소를 로컬 저장소에 연결.

#### 4.2 푸시 (Push)
- **명령어**: `git push -u origin [branch-name]`
- **설명**: 로컬 브랜치의 변경 사항을 원격 저장소에 푸시.

#### 4.3 풀 (Pull)
- **명령어**: `git pull origin [branch-name]`
- **설명**: 원격 저장소의 변경 사항을 로컬로 가져옴.

### 5. 충돌 해결

#### 5.1 병합
- **명령어**: `git merge [branch-name]`
- **설명**: 현재 브랜치에 다른 브랜치의 변경 사항을 병합.

#### 5.2 충돌 해결
1. 충돌 발생한 파일 확인.
2. 파일 열어 충돌 부분 수정.
3. 수정 후 스테이징:
   ```bash
   git add [file]
   ```
4. 변경 사항 커밋:
   ```bash
   git commit -m "Resolved merge conflict"
   ```

### 6. Git 로그 확인
- **명령어**: `git log`
- **설명**: 커밋 히스토리 확인.
