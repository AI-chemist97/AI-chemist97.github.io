# 데이터 분석을 위한 수학 공부
데이터 분석을 통해 입자의 합성과 특성을 예측하고 실험의 재현성을 높이면서도 예측한 반응을 통해 실험에 소요되는 비용과 시간을 줄이는 것은 오래전부터 내 관심사였다.
대학에서 화학을 전공하고 대학원에서 재료화학공학을 전공하며 실험과 분석에 많은 시간을 보냈고, 실험을 진행하면서 투여하는 시약의 양 가열 시간과 온도와 같은 여러 변인들을 통제하며 문제해결의 즐거움을 알게 되었다.

이러한 과정에서 보다 효율적인 실험을 위해 데이터 분석에 대해 관심을 가지게 되었고, 그 과정에서 **수학적 지식**이 데이터 분석에 많은 영향을 끼치고 있다는 것을 알게되었다. 하지만 자연대인 화학과의 경우 학부 과정 중 수학을 따로 배우지 않아, 수학적 기초가 부족하다고 생각하였고, 이로 인해 관련 자료를 찾고 이해하는데도 어려움이 있었다.

그래서 수학의 기초를 이해하고, 이러한 지식을 데이터 분석에 적용하고자 공부를하려 한다.
데이터 분석에서 잘 보이는 회귀 분석과 베이지안 추론 같은 이름도 흔하지 않은 이런 기법들을 배우기 위해 수학적 기초를 공부하고자 한다.

## 공부 목표
### 단기 목표(1개월)
* 기초 수학 및 통계 개념 확실히 하기
    * 1. 수학 기초 복습: 중학교 수학 총정리, 고1 함수, 수와 연산, 함수, 확률 기초와 같은 것을 빠르게 흝기
    * 2. 데이터 분석에 꼭 필요한 수학(통계/확률 기초):
        * 평균, 분산, 표준편차
        * 확률분포(정규분포, 이항분포)
        * 상관관계 vs 인과관계
        * 독립/조건부확률
        * [Khan Academy - Statistics & Probability](https://ko.khanacademy.org/math/statistics-probability)
        * [생활코딩](https://www.youtube.com/@coohde)
    * 3. 회귀분석과 P-value, 잔차 분석(회귀분석 & 선형대수):
        * 선형회귀, 다중회귀, p-value, 잔차, 선형방정식: Python, statsmodels, numpy
        * 회귀분석: 데이터에서 예측값을 뽑아내는 기법 (ex. 공부시간->시험점수)
        * P-value: 예측이 "우연이 아닌" 통계적 의미가 있는지 판단하는 값 (0.05 기준)
        * 잔차 분석: 예측값과 실제값의 차이를 보는 것 -> 모델의 정확도 평가
            ```
            import statsmodels.api as sm
            X = df[['공부시간']]
            y = df['점수']
            X = sm.add_constant(X)
            model = sm.OLS(y, X).fit()
            print(model.summary())

            ```

    * 4. 머신러닝 기초:

        * 시각화&비율분석: 서울시 교통사고(사고 원인 탐색)
