# Django 실행 순서
가상 환경은 굳이 없어도 되지만 있는게 마음이 편하다

```bash
python -m venv venv
```
설치 위치는 프로젝트 파일과 나란하게
```bash
/my_project
│
├── /my_app               # Django 앱 폴더
│   ├── migrations
│   ├── __init__.py
│   ├── models.py
│   ├── views.py
│   └── ...
│
├── /my_project            # Django 프로젝트 설정 폴더
│   ├── __init__.py
│   ├── settings.py
│   ├── urls.py
│   └── ...
│
├── manage.py             # Django 프로젝트 관리 스크립트
├── requirements.txt      # 의존성 패키지 목록 (없을 수도 있음)
└── README.md             # 프로젝트 설명 파일
```
이런 느낌으로 설치

만약 프로젝트를 git으로 동업하거나 하고 있어서 설치해야할 pip 라이브러리가 있다면
requirements.txt 파일에 저장하고 설치한다.
```bash
pip freeze > requirements.txt
pip install -r requirements.txt
```
freeze는 파일을 만들고 install 은 설치한다 막 시작한다면 설치만 하면된다.
